One sentence about the best meal I ever had: instant mie goreng eaten on a ferry deck at sunrise, salt wind in my face and my wife asleep on my shoulder. `main.py` writes that single sentence to `entry.txt` and validates it against the kit gate (one sentence, at most 200 characters).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/best-meal-out python3 main.py
```
